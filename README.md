# 🚀 Gemini Code Assist for GitHub

本專案致力於探索與測試 **Gemini Code Assist For GitHub** 的強大功能，提升團隊開發效率與程式碼品質！ 🤖✨

---

## 🌟 介紹 (Introduction)
參考 Google 官方文件：[使用 Gemini Code Assist 檢查 GitHub 程式碼](https://developers.google.com/gemini-code-assist/docs/review-github-code?hl=zh-tw) 🔍

- **AI 審查員**：讓 Gemini Code Assist 扮演專業的程式碼審查員（Code Reviewer），主動發現潛在問題。
- **自動化體驗**：高度整合 GitHub 工作流，讓開發過程更流暢。

## 📥 安裝 (Installation)
1. 點擊進入安裝網頁：[Gemini Code Assist for GitHub](https://github.com/apps/gemini-code-assist) 🌐
2. 按下 **Install** 按鈕。
3. 按照提示完成授權與驗證核准即可啟用！ ✅

## 💡 使用說明 (Usage)
所有的核心功能皆在 **Pull Requests (PR)** 頁面進行。 🛠️
- 您可以參考此[範例 PR](https://github.com/jojochuang/ozone/pull/566) 來查看 Gemini 的實際運作效果。

## ⌨️ 指令手冊 (Commands)
在 PR 的註解中輸入以下指令，即可呼叫 Gemini 執行任務：

| 指令 | 說明 |
| :--- | :--- |
| `/gemini summary` | 📝 在 PR 中發布自動生成的變更摘要。 |
| `/gemini review` | 🔍 針對程式碼變更內容進行深度審查。 |
| `/gemini` | 🗨️ 在註解中手動叫用 Gemini 進行對話。 |
| `/gemini help` | ❓ 顯示所有可用指令的總覽。 |
